# ReminderHub Cat Companion Assets

This folder is reserved for modular 2D cat image assets (PNG / SVG).
The pet engine uses dynamic Flutter vector rendering (`PetCatPainter`) by default with modular components:
- Body
- Head
- Eyes (Open, Blinking, Sleeping, Surprised)
- Ears
- Tail
- Front & Back Paws
- Study Accessories (Book, Backpack)

Optional component images:
- `body.png`
- `head.png`
- `eyes.png`
- `mouth.png`
- `ears.png`
- `tail.png`
- `paw_left.png`
- `paw_right.png`
- `backpack.png`
- `book.png`

When custom images are placed here, they can be utilized directly by the component rendering pipeline.
